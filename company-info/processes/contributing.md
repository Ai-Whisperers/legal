# Contributing to AI Whisperers Projects

Thank you for your interest in contributing to AI Whisperers projects!

---

## For Team Members

### Getting Started
1. Review project README
2. Set up development environment
3. Understand project architecture
4. Check existing issues/tasks

### Development Process
1. Create feature branch from `develop`
2. Make changes with clear commits
3. Test thoroughly
4. Create pull request
5. Address review feedback
6. Merge when approved

### Code Standards
- Follow project coding style
- Write meaningful commit messages
- Add tests for new features
- Update documentation
- Keep PRs focused and manageable

### Communication
- Ask questions early
- Document decisions
- Share knowledge
- Be respectful and professional

---

## For Contractors

### Before Starting
- Sign contractor agreement
- Review IP policy
- Understand project scope
- Set up secure environment

### Deliverables
- Meet agreed specifications
- Provide clean, documented code
- Pass all tests
- Transfer all work product
- No retention of code/IP

### Confidentiality
- Protect client information
- Use secure communication
- Return/destroy materials after project
- No disclosure without authorization

---

## Code Review Guidelines

### As Reviewer:
- Be constructive and respectful
- Focus on code, not person
- Explain reasoning
- Approve when standards met

### As Author:
- Welcome feedback
- Respond to comments
- Make requested changes
- Ask for clarification if needed
