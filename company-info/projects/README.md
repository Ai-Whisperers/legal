## 📝 Adding New Projects

When starting a new project, create:

1. **Project Document** (`project-name.md`)
   - Overview and objectives
   - Technical approach
   - Timeline and milestones
   - Team and resources

2. **Project Reports** (`Project-Name-Report-YYYY-MM-DD.md`)
   - Progress updates
   - Findings and results
   - Lessons learned
   - Next steps
