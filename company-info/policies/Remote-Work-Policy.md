## 4. WORKSPACE REQUIREMENTS

### 4.1 Home Office Setup

**Minimum requirements:**
- Dedicated, quiet workspace
- Ergonomic furniture (desk, chair)
- Adequate lighting
- Professional background for video calls

**Recommendations:**
- Separate room if possible
- Minimized distractions
- Organized workspace
- Appropriate temperature control

### 4.2 Internet and Connectivity

**Required:**
- High-speed internet (minimum 25 Mbps download, 5 Mbps upload)
- Reliable connection
- Backup connectivity option (mobile hotspot)
- VPN for company network access

### 4.3 Equipment

- Laptop/desktop computer
- Necessary software licenses
- Security tools
- Communication tools

**Employee-Provided:**

## 7. SECURITY AND CONFIDENTIALITY

### 7.1 Data Security

**Requirements:**
- Full disk encryption
- VPN for all company access
- Secure Wi-Fi (WPA3/WPA2, strong password)
- No public Wi-Fi for sensitive work
- Screen privacy filters in public

### 7.2 Device Security

**Mandatory:**
- Company-provided or approved devices only
- Antivirus and anti-malware
- Automatic updates enabled
- Screen lock (< 5 minutes)
- Lost/stolen device reporting immediately

### 7.3 Confidentiality

**Protect sensitive information:**
- No discussions in public places
- Secure documents from household members
- Shred confidential documents
- No client names in public spaces
- Follow clean desk policy

### 7.4 Workspace Security

**Physical security:**
- Lock screens when away
- Secure equipment
- Household member awareness
- No unauthorized system access by others
